# Crab

Claude Code 기반 개발 워크스테이션. macOS(Apple Silicon) 전용.

이 저장소는 릴리즈 전용이다 — 바이너리와 자동 업데이트 피드(`latest-mac.yml`)만 올라온다. 소스는 비공개다.

## 설치

[Releases](../../releases)에서 최신 dmg를 받아 설치한다. 서명·공증돼 있어 Gatekeeper를 그대로 통과한다. 이후 업데이트는 앱이 스스로 받는다.

## 화면 구성

- **좌 사이드바** — 프로젝트 · JIRA · GitHub · Bitrise. 프로젝트 카드를 펼치면 그 repository의 worktree와, 각 워크스페이스에서 돌고 있는 세션이 함께 선다. 세션 줄에는 상태 배지와 Claude 세션 이름이 뜬다.
- **컬럼** — 화면을 좌우로 나눠 워크스페이스 둘을 나란히 놓는다. 탭은 컬럼이 아니라 워크스페이스가 소유한다.
- **세션 탭** — 탭 하나가 곧 터미널 하나. 새 탭에서 Claude Code 세션 또는 셸을 고른다. 분할하면 한 탭 안에 여러 칸이 나란히 보인다.
- **뷰어 칸** — 파일·이미지·비디오·웹 탭 전용 컬럼. 자체 탭바를 갖고 프로젝트에 묶이지 않는다. 첫 파일을 열면 나타나고 마지막 탭을 닫으면 걷힌다.
- **우 패널** — 탐색기 · `.claude` · 소스 컨트롤 · 이력 · 시뮬레이터

## worktree

worktree 하나가 워크스페이스 하나다. 프로젝트 카드를 우클릭해 만들고, 지우는 것도 거기서 한다. 새 branch를 파도 되고, 이미 있는 branch나 `origin/…`를 골라도 된다 — remote를 고르면 tracking branch를 알아서 판다.

목록의 정본은 `git worktree list`다. 앱이 따로 적어 두지 않으므로 터미널에서 만든 worktree도 그대로 뜬다.

만든 직후 세 가지가 이어서 일어난다.

1. **링크** — git이 추적하지 않는 파일·폴더를 symlink로 건다. 기본은 `.env`이고, 설정 › 일반에서 늘린다(`.claude`, `CLAUDE.md` 등). 복사가 아니라 링크라 한쪽에서 고치면 양쪽에 반영된다.
2. **셋업 스크립트** — 프로젝트마다 정한 셸 스크립트를 새 worktree에서 한 번 돌린다. 프로젝트 우클릭 → **worktree 셋업**. repository마다 다른 일이 필요하다 — 한쪽은 `pnpm install`, 다른 쪽은 `xcode-build-server config`다. 화면에서 돌기 때문에 실패하면 그 자리에서 보이고, 실패하면 에이전트를 안 띄우고 셸에 남는다.
3. **세션** — 그 워크스페이스로 화면을 옮기고 Claude 세션을 띄운다. 설정 › 일반에서 끌 수 있다.

## 뷰어

탐색기에서 파일을 클릭하면 뷰어 칸에 열린다. 코드 파일은 Monaco로 편집하고 ⌘S로 저장한다. 마크다운은 프리뷰와 편집을 토글하고, 이미지·비디오는 그대로 재생된다.

### JSON

`.json` 파일은 트리로 열린다. 로그에서 복사한 덩어리도 ⇧⌘J로 같은 화면에 붙는다 — 접두사가 붙어 있거나 이스케이프로 감싸여 있어도, JSON 문서가 여럿 이어져 있어도 벗겨서 읽는다.

- **찾기(⌘F)** — 접힌 가지 안까지 훑고, 걸린 줄이 보이도록 그 조상만 펼친다. ⏎와 ⇧⏎로 결과 사이를 옮긴다.
- **지우기** — 줄의 ✕나 ⌫로 가지 하나를, 우클릭으로 같은 키를 전부 지운다. 큰 응답에서 필요한 조각만 남길 때 쓴다. **되돌리기**로 한 걸음씩 물린다.
- **원문에 반영** — 지운 결과를 편집기 내용으로 갈아 끼운다. ⌘Z가 이어지고, ⌘S로 그대로 저장된다.
- **복사** — 줄을 누르면 값, ⌥을 누른 채면 경로. 우클릭에 키·값·경로가 다 있다. 헤더의 **정리해 복사**는 전체를 포맷해 넘긴다.

## 단축키

| 키 | 동작 |
| --- | --- |
| ⌘, | 설정 |
| ⌘/ | 단축키 도움말 |
| ⌘B | 사이드바 접기 |
| ⌘T | 새 탭 |
| ⌘W | 닫기 — 뷰어를 보고 있으면 뷰어 탭, 아니면 현재 세션 |
| ⌘D | 오른쪽으로 스플릿 (새 칸에 바로 셸이 뜬다) |
| ⇧⌘D | 아래로 스플릿 |
| ⌘⏎ | 현재 칸 최대화 토글 |
| ⌥⌘ ← → ↑ ↓ | 페인 포커스 이동 |
| ⌘F | 페인 안에서 찾기 — 터미널 검색, JSON 트리 검색 |
| ⌘+ / ⌘− / ⌘0 | 크게 · 작게 · 기본 크기로 — 터미널은 글자 크기, 뷰어·웹 탭은 배율 |
| ⌘S | 뷰어에서 파일 저장 |
| ⇧⌘J | JSON으로 열기 — 터미널에서 고른 글자, 없으면 클립보드 |
| ⇧⏎ | 터미널 줄바꿈 — Claude Code 입력에서 전송 없이 줄을 바꾼다 |
| ⌥ 누르고 있기 | 현재 세션 폴더를 다른 앱(IDE·터미널 등)으로 여는 오버레이 |
| ⌘⏎ (소스 컨트롤) | 커밋 |
| Esc | 다이얼로그·메뉴 닫기 |

시뮬레이터 화면에 포커스가 있을 때는 ⇧⌘H 홈 · ⌘L 잠금 · ⌘← → 회전 · ⌘↑ ↓ 볼륨.

## 쓰는 법 몇 가지

- 앱을 다시 켜면 세션 화면이 그대로 복원된다. 프로세스는 죽어 있고 화면만 읽기 전용으로 남는데, 배너의 **재개**로 이어서 시작한다.
- 세션 줄의 이름 칩을 누르면 그 Claude 세션 이름이 복사된다. 다른 세션에서 그 이름으로 메시지를 보낼 때 쓰는 주소다.
- JIRA 이슈나 GitHub PR 행을 우클릭하면 스킬 메뉴가 뜬다. 고른 스킬로 해당 이슈·PR을 물고 Claude Code 세션이 시작된다.
- 우 패널의 **이력**은 지난 Claude 세션 기록을 프로젝트 단위로 모아 보여 준다. 검색해서 그때 오간 대화를 다시 읽는다.
- 우 패널의 **시뮬레이터**는 iOS 시뮬레이터 화면을 앱 안에 띄운다. 탭·스와이프·회전·녹화까지 여기서 끝난다 — Simulator.app으로 창을 옮길 일이 없다.

## 실험실

확신이 덜 선 기능은 **설정 › 실험실** 뒤에 있고 기본은 꺼져 있다. 끄면 그 기능의 조작면이 화면에서 전부 사라진다.

- **Loop 모드** — Claude 페인에 할 일 목록을 붙여 둔다. `- [ ]` 체크리스트에서 항목을 골라 담으면, 에이전트가 턴을 마칠 때마다 다음 항목을 자동으로 넣어 목록을 다 처리할 때까지 돌린다.
