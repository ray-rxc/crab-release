# Crab

Claude Code 기반 개발 워크스테이션. macOS(Apple Silicon) 전용.

이 저장소는 릴리즈 전용이다 — 바이너리와 자동 업데이트 피드만 올라온다. 소스는 비공개다.

## 설치

[Releases](../../releases)에서 최신 dmg를 받는다. 서명·공증돼 있어 Gatekeeper를 그대로 통과하고, 이후 업데이트는 앱이 스스로 받는다.

## 화면

- **좌 사이드바** — 프로젝트 · JIRA · GitHub · Bitrise. 프로젝트를 펼치면 worktree와 각 워크스페이스의 세션이 선다.
- **컬럼** — 화면을 좌우로 나눠 워크스페이스 둘을 나란히 놓는다.
- **세션 탭** — 탭 하나가 터미널 하나. Claude 세션이나 셸을 고르고, 분할하면 한 탭에 여러 칸이 뜬다.
- **뷰어 칸** — 파일·이미지·비디오·웹 전용 컬럼. 첫 파일에 나타나고 마지막 탭을 닫으면 걷힌다.
- **우 패널** — 탐색기 · `.claude` · 소스 컨트롤 · 이력 · 시뮬레이터

## worktree

worktree 하나가 워크스페이스 하나다. 프로젝트를 우클릭해 만들고 지운다. 목록의 정본은 `git worktree list`라, 터미널에서 만든 것도 그대로 뜬다.

만들면 세 가지가 이어진다.

1. `.env` 같은 추적 안 되는 파일을 symlink로 건다 (설정 › 일반에서 목록을 늘린다)
2. 프로젝트마다 정한 셋업 스크립트를 돌린다 (우클릭 → worktree 셋업)
3. 그 워크스페이스에 Claude 세션을 띄운다 (설정에서 끌 수 있다)

## 뷰어

파일을 클릭하면 뷰어 칸에 열린다. 코드는 Monaco로 편집하고 ⌘S로 저장, 마크다운은 프리뷰 토글, 이미지·비디오는 그대로 재생.

`.json`은 트리로 열린다. 로그에서 복사한 덩어리도 ⇧⌘J로 같은 화면에 붙는다 — 접두사나 이스케이프가 붙어 있어도 벗겨서 읽는다.

- **⌘F** — 접힌 가지 안까지 찾고, 걸린 줄만 펼친다. ⏎ / ⇧⏎로 이동
- **제거** — ✕나 ⌫로 한 줄, 우클릭으로 같은 키 전부. **되돌리기**로 물린다
- **원문에 반영** — 지운 결과를 편집기에 되돌려 ⌘S로 저장한다

## 단축키

| 키 | 동작 |
| --- | --- |
| ⌘, · ⌘/ · ⌘B | 설정 · 단축키 도움말 · 사이드바 접기 |
| ⌘T · ⌘W | 새 탭 · 닫기 |
| ⌘D · ⇧⌘D | 오른쪽 · 아래로 스플릿 |
| ⌘⏎ | 현재 칸 최대화 |
| ⌥⌘ ← → ↑ ↓ | 페인 포커스 이동 |
| ⌘F | 페인 안에서 찾기 |
| ⌘+ ⌘− ⌘0 | 크게 · 작게 · 기본 |
| ⌘S | 파일 저장 |
| ⇧⌘J | 고른 글자(없으면 클립보드)를 JSON으로 열기 |
| ⇧⏎ | 터미널 줄바꿈 — 전송 없이 줄을 바꾼다 |
| ⌥ 누르고 있기 | 현재 폴더를 다른 앱으로 여는 오버레이 |
| ⌘⏎ (소스 컨트롤) | 커밋 |

시뮬레이터에 포커스가 있을 때 — ⇧⌘H 홈 · ⌘L 잠금 · ⌘← → 회전 · ⌘↑ ↓ 볼륨.

## 몇 가지

- 앱을 다시 켜면 세션 화면이 복원된다. 프로세스는 죽어 있고, 배너의 **재개**로 이어서 시작한다.
- 세션 줄의 이름 칩을 누르면 그 Claude 세션 이름이 복사된다. 다른 세션에서 메시지를 보낼 때 쓰는 주소다.
- JIRA 이슈나 GitHub PR을 우클릭하면 스킬 메뉴가 뜬다. 고른 스킬로 그 이슈·PR을 물고 세션이 시작된다.
- **시뮬레이터** 패널은 iOS 시뮬레이터를 앱 안에 띄운다. 탭·스와이프·회전·녹화까지 여기서 끝난다.

## 실험실

확신이 덜 선 기능은 **설정 › 실험실** 뒤에 있고 기본은 꺼져 있다.

- **Loop 모드** — `- [ ]` 체크리스트에서 항목을 골라 담으면, 턴이 끝날 때마다 다음 항목을 자동으로 넣어 목록을 다 처리할 때까지 돌린다.
